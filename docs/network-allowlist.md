# Network inventory

Loqui has no hosted backend or OpenWhispr service dependency. Optional features still make network requests. See [privacy and network behavior](PRIVACY.md) for what each request can contain and how to disable it.

This document is an inventory, **not an enforced firewall allowlist**. Model sources can redirect to storage/CDN hosts, custom endpoints are user-selected, URL imports can contact arbitrary chosen sites, and Codex manages its own service connections. Do not assume that allowing a short list of domains captures all possible destinations.

| Group                                  | Source of the exact destination                                                                                                                                                                                            | Planned Sealed mode (07a incomplete)                                                                   |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Loqui updates                          | `src/config/product.json`, `electron-builder.cjs`, and the main-process update manager; only the Loqui GitHub repository is configured                                                                                     | Blocked                                                                                                |
| Build runtimes and support models      | `runtime-assets.json` plus dependency installation; archives and licenses belong to their upstream projects                                                                                                                | Developer/CI build activity outside app scope; in-app downloads blocked                                |
| User-selected local models             | `src/models/modelRegistryData.json` and local model managers                                                                                                                                                               | Downloads blocked; built-in native engines unavailable                                                 |
| API providers and compatible endpoints | The chosen provider's integration and explicit endpoint settings                                                                                                                                                           | Nonloopback blocked; explicitly configured loopback transport eligible, subject to native restrictions |
| ChatGPT subscription                   | OpenAI’s `openai/codex` release metadata at `api.github.com`, release assets at `github.com` and its asset CDN for binary verification, plus the installed Codex app-server’s managed authentication/inference connections | Blocked (verification, probes and native app-server)                                                   |
| Google/Microsoft calendars             | `googleCalendarOAuth.js`, `googleCalendarManager.js`, `microsoftCalendarOAuth.js`, and `microsoftCalendarManager.js` in `src/helpers/`                                                                                     | Blocked (including native Apple helpers where applicable)                                              |
| URL imports                            | The selected URL, redirects, and associated media sources                                                                                                                                                                  | Blocked                                                                                                |

**Partial 07a status:** this column states required behavior for the planned main-owned gates, Node/Chromium backstops and spawn admission; Task 1 adds documentation and inventory ratchets, not runtime enforcement. Every platform native boundary remains unavailable: `nothingLeaves=false`, `effectiveSince=null`. While sealed, all native starts (including built-in local models, FFmpeg, OS tools, relaunch and updater install/restart) must refuse until independently verified 07b controls exist. Main transport loopback eligibility does not prove native availability or that a user-owned loopback forwarder stays on this machine. Browser/mail, fixed settings and file-manager handoffs require main-owned confirmation and outside-app disclosure; confirmation does not waive native-launch refusal. The merge gate remains open under D14–D16.

The current source inventory is now checked by `test/helpers/egressInventory.test.js`. Per-path N1–N26 decisions, metadata-only recorder semantics, process/service/resource coverage and remaining proof obligations are in the [Sealed mode threat model](security/sealed-mode-threat-model.md).

For fully offline use, prepare the local models you need, select local providers, disable automatic updates, and leave remote calendar/import/search integrations unused or disconnected. Verify the workflow in a disconnected environment; a successful browser simulation does not establish offline desktop behavior.

Contributions that add a network destination or send a new category of user content must update this inventory and the privacy documentation.
