### Task 7: Route drafts: instant on-device, staged off-device, Undo (SET-R3 B core, SET-Q10)

Closes **I1** (store core: classification by the planner's effective result, not by `target.mode`), **I3** (planning waits for acknowledged key saves and then reads main's credential presence) and **I14** (plans read the single sealed authority). It completes **I5** for Undo. INTEGRATION-A: `requestRoutePatch` gives the enable switches, the Corti region and tenant, and the provider web-search preference the same instant/staged/noop rules as a route change.

Every way of changing a route (the mode selectors, pickers, endpoint fields, enable switches, Corti region and web-search toggle in Tasks 8–9, the Patchbay in Task 10) calls this module. The rules:
- **Planning.** A request first awaits `flushSecretSaves()` (Task 2), then `refreshRouteFacts(["credentials"])` (Task 3), so a key saved a moment ago counts as present without waiting for main's `credentials-changed` event. It is then planned against the live settings, main's facts and `getSealed()`.
- **Two entry points.** `requestRouteChange(id, target, copy)` plans a destination; `requestRoutePatch(id, patch, copy)` plans raw route keys (switches, Corti options, `providerSearch:<scope>`). Both follow the same kind rules, and a staged patch becomes a `kind: "patch"` draft.
- **By plan kind:**
  - `noop`: nothing is written, and any draft for that route is dropped.
  - `instant`: the plan's patch is committed, and an Undo is returned. Every changed route either ends on this device, or keeps the same recipient and payload.
  - `staged`: the request becomes the single draft, and nothing is written.
- **Apply.** It awaits pending key saves, then re-plans the draft from the live state at click time. It refuses with a blocker and keeps the draft, or commits.
- **Undo.** It re-plans the prior raw values. A move back onto the device (or to the same recipient) applies at once; anything else is staged as a patch draft. Undo never moves work off the device without review.
- **Closing Settings** discards the draft (`withDraftDiscard`).

   ```ts
   import { create } from "zustand";
   import { INFERENCE_SCOPES } from "../config/inferenceScopes";
   import type { SettingsPatch } from "../lib/providerSwitchPlans";
   import {
     planPatch,
     planRouteChange,
     type ApplyBlocker,
     type PlanContext,
     type RoutePlan,
     type RouteTarget,
   } from "../lib/routePlanner";
   import type { RouteCopy, RouteId } from "../lib/routes";
   import { refreshRouteFacts, useRouteFactsStore } from "./routeFactsStore";
   import { getSealed } from "./sealedStore";
   import { flushSecretSaves, useSettingsStore } from "./settingsStore";

   // The single place that changes where a task runs (SET-R3 B). Each request
   // is planned (routePlanner.ts). Results that stay on this device, or keep
   // the same recipient and payload, apply at once with Undo. Anything that
   // adds an off-device recipient or payload waits as the one draft until Apply.

   export type RouteDraft =
     | { routeId: RouteId; kind: "target"; target: RouteTarget }
     | { routeId: RouteId; kind: "patch"; patch: SettingsPatch };

   interface RouteDraftState {
     draft: RouteDraft | null;
     stage: (draft: RouteDraft) => void;
     discard: () => void;
   }

   export const useRouteDraftStore = create<RouteDraftState>()((set) => ({
     draft: null,
     stage: (draft) => set({ draft }),
     discard: () => set({ draft: null }),
   }));

   export interface RouteChangeOutcome {
     applied: boolean;
     blocker: ApplyBlocker | null;
     plan: RoutePlan;
     undo?: () => RouteChangeOutcome | "staged";
   }

   // Readiness facts confirmed by main, and the single sealed authority (I14).
   export function currentPlanContext(copy: RouteCopy): PlanContext {
     return { facts: useRouteFactsStore.getState().facts, copy, sealed: getSealed() };
   }

   // What a draft would commit against the live state right now. The Apply bar
   // renders this; Apply re-runs it at click time.
   export function planDraft(draft: RouteDraft, copy: RouteCopy): RoutePlan {
     const state = useSettingsStore.getState();
     const ctx = currentPlanContext(copy);
     return draft.kind === "target"
       ? planRouteChange(state, ctx, draft.routeId, draft.target)
       : planPatch(state, ctx, draft.routeId, draft.patch);
   }

   const LLM_MODE_KEYS: ReadonlySet<string> = new Set(
     Object.values(INFERENCE_SCOPES).map((def) => def.storeKeys.mode as string)
   );

   function discardDraftFor(routeId: RouteId): void {
     const { draft, discard } = useRouteDraftStore.getState();
     if (draft?.routeId === routeId) discard();
   }

   function commit(plan: RoutePlan, copy: RouteCopy): RouteChangeOutcome {
     useSettingsStore.getState().applyRoutePatch(plan.patch);
     // Like InferenceConfigEditor.tsx:115-117: a scope moving to a server frees
     // the local llama-server.
     const toServer = Object.entries(plan.patch).some(
       ([key, value]) => LLM_MODE_KEYS.has(key) && value === "self-hosted"
     );
     if (toServer) window.electronAPI?.llamaServerStop?.()?.catch(() => {});
     // Main keeps the dictation overlay out of its own screenshots while screen
     // context is on (DictationAgentSettings.tsx:61 did this before the switch
     // went through the planner). Here it follows every commit: instant, Apply, Undo.
     if (typeof plan.patch.voiceAgentScreenContext === "boolean") {
       window.electronAPI?.setScreenContextEnabled?.(plan.patch.voiceAgentScreenContext)?.catch(() => {});
     }
     // A change on this route supersedes any draft for it.
     discardDraftFor(plan.routeId);
     return { applied: true, blocker: null, plan, undo: () => undo(plan, copy) };
   }

   // Undo re-plans the prior raw values against the live state. Back onto the
   // device, or to the same recipient, is instant. Anything that would send
   // data somewhere new is staged for review, never applied by Undo itself.
   function undo(plan: RoutePlan, copy: RouteCopy): RouteChangeOutcome | "staged" {
     const reverse = planPatch(
       useSettingsStore.getState(),
       currentPlanContext(copy),
       plan.routeId,
       plan.undoPatch
     );
     if (reverse.kind === "noop") return { applied: false, blocker: null, plan: reverse };
     if (reverse.kind === "instant") return commit(reverse, copy);
     useRouteDraftStore
       .getState()
       .stage({ routeId: plan.routeId, kind: "patch", patch: plan.undoPatch });
     return "staged";
   }

   // A key typed a moment ago must be saved and acknowledged by main, and
   // main's presence for it read back, before a plan reads key readiness (I3).
   // credentials.list is a local IPC read; it never touches the network.
   async function readyToPlan(): Promise<void> {
     await flushSecretSaves();
     await refreshRouteFacts(["credentials"]);
   }

   // Shared by both request paths: noop drops the route's draft, instant
   // commits with Undo, staged becomes the single draft.
   function settle(plan: RoutePlan, draft: RouteDraft, copy: RouteCopy): RouteChangeOutcome | "staged" {
     if (plan.kind === "noop") {
       // Re-selecting where the task already runs changes nothing and cancels its draft.
       discardDraftFor(plan.routeId);
       return { applied: false, blocker: null, plan };
     }
     if (plan.kind === "instant") return commit(plan, copy);
     useRouteDraftStore.getState().stage(draft);
     return "staged";
   }

   export async function requestRouteChange(
     id: RouteId,
     target: RouteTarget,
     copy: RouteCopy
   ): Promise<RouteChangeOutcome | "staged"> {
     await readyToPlan();
     const plan = planRouteChange(useSettingsStore.getState(), currentPlanContext(copy), id, target);
     return settle(plan, { routeId: id, kind: "target", target }, copy);
   }

   // Raw route keys that are not a destination: the enable switches, Corti's
   // region and tenant, and providerSearch:<scope>. Turning a route on toward
   // an off-device recipient, or adding a payload part, is staged; turning a
   // route off is instant.
   export async function requestRoutePatch(
     id: RouteId,
     patch: SettingsPatch,
     copy: RouteCopy
   ): Promise<RouteChangeOutcome | "staged"> {
     await readyToPlan();
     const plan = planPatch(useSettingsStore.getState(), currentPlanContext(copy), id, patch);
     return settle(plan, { routeId: id, kind: "patch", patch }, copy);
   }

   export async function applyDraft(copy: RouteCopy): Promise<RouteChangeOutcome | null> {
     const draft = useRouteDraftStore.getState().draft;
     if (!draft) return null;
     await readyToPlan();
     // The user applied this draft. If it was discarded or replaced while saves
     // finished, apply nothing.
     if (useRouteDraftStore.getState().draft !== draft) return null;
     const plan = planDraft(draft, copy); // live state, at click time
     if (plan.kind === "noop") {
       useRouteDraftStore.getState().discard();
       return { applied: false, blocker: null, plan };
     }
     if (plan.blocker) return { applied: false, blocker: plan.blocker, plan }; // draft kept
     return commit(plan, copy);
   }

   // Closing Settings discards the draft without applying it.
   export function withDraftDiscard(
     onOpenChange: (open: boolean) => void
   ): (open: boolean) => void {
     return (open) => {
       if (!open) useRouteDraftStore.getState().discard();
       onOpenChange(open);
     };
   }
   ```

2. Create `src/lib/routeChangeMessage.ts`:

   ```ts
   import { providerDisplayLabel } from "./locality";
   import type { RoutePlan } from "./routePlanner";

   // Toast copy for a committed or applied route change (SET-Q10). Names the
   // destination (provider via providerDisplayLabel, or the server host) and
   // what is sent, plus any coupled routes that changed with it.

   export type Translate = (key: string, options?: Record<string, unknown>) => string;

   export interface RouteChangeMessage {
     title: string;
     description?: string;
   }

   export function routeChangeMessage(
     plan: Pick<RoutePlan, "routeId" | "changes">,
     t: Translate,
     list: (items: string[]) => string
   ): RouteChangeMessage {
     const main = plan.changes.find((change) => !change.coupled) ?? plan.changes[0];
     if (!main) return { title: t("routes.toast.saved", { task: t(`routes.names.${plan.routeId}`) }) };

     const route = main.after;
     const task = t(`routes.names.${route.id}`);
     const provider = route.providerId ? providerDisplayLabel(route.providerId, t) : "";
     const destination =
       route.locality === "device"
         ? t("routes.toast.thisDevice")
         : route.locality === "network"
           ? route.host
             ? t("routes.toast.serverAt", { host: route.host })
             : t("routes.toast.server")
           : provider;

     const turnedOff = route.state.status === "off" && main.before.state.status !== "off";
     const title = turnedOff
       ? t("routes.toast.off", { task })
       : route.state.status === "off"
         ? t("routes.toast.whenOn", { task, destination })
         : route.locality === "device"
           ? t("routes.toast.local", { task })
           : t("routes.toast.sends", { task, payload: route.sends ?? "", destination });

     const notes: string[] = [];
     if (route.state.status === "needsModel") notes.push(t("routes.toast.chooseModel"));
     if (route.state.status === "needsKey" && provider) {
       notes.push(t("routes.toast.signInNext", { provider }));
     }
     const coupled = plan.changes
       .filter((change) => change !== main)
       .map((change) => t(`routes.names.${change.id}`));
     if (coupled.length > 0) notes.push(t("routes.toast.alsoChanges", { tasks: list(coupled) }));

     return notes.length > 0 ? { title, description: notes.join(" ") } : { title };
   }
   ```

   Callers (Task 8 onwards) pass `t` from `useTranslation()` and the `list` from the same `RouteCopy` they plan with (`copy.list`, the `Intl.ListFormat` conjunction).
