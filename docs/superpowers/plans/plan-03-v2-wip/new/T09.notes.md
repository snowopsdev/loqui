  - `OpenAICompatiblePanel` is rewritten. It no longer runs the mount discovery (:225-237), the blur commit and discovery (:239-252), the sibling-base loop that auto-adopted a different base URL (:165-193), Apply & Refresh, or Reset as a direct write.
  - URL edits live in `EndpointDraft`'s local state. "Use this endpoint" calls `onUseEndpoint`, which every caller routes through `requestRouteChange`.
  - The single `personalInference.models(` call site is the **List models** button. Its label names the committed host (`BidiInterpolatedText`). Its title and caption name the slot main sends (`custom:<scope>` → "the custom-endpoint key saved for {task}"; `openrouter` → "your saved OpenRouter key"), or say that no key is sent.   - `CodexModelPicker` no longer lists models on mount. Mounted tests (probe pattern):
    - zero calls on mount, on re-render with another committed base, on input `onChange`, with no `onBlur` handler, and on "Use this endpoint";
    - exactly one call, with the committed host and `credentialRef`, after the button's `onClick`;
    - zero calls when browsing ReasoningModelSelector's custom, OpenRouter and Codex tabs.
- **I1 (pickers).**
  - `TranscriptionModelPicker`: `handleCloudModelSelect`, local model picks, the mode toggle and the custom endpoint (URL and model as one draft) all call `onCommit`. `handleBaseUrlBlur` (automatic provider recognition), per-keystroke URL and model writes, and the policy-reconcile write effect are deleted.
  - `ReasoningModelSelector`: `handleModelSelect`, `handleModeChange`, the OpenRouter and custom panels and enterprise picks call `onCommit`.
  - `SelfHostedPanel` is a draft with "Use this server". Upload's copy is read-only.
  - All parents wire `onCommit` through `useRouteCommit(routeId)` → `requestRouteChange`.
  - Tests:
    - local → loopback is instant (SelfHostedPanel "Use this server" on dictation);
    - loopback → remote is staged (speech custom endpoint and text custom endpoint);
    - changing an active remote endpoint is staged;
    - a model change at the same provider is instant (speech and text);
    - the NotesOnboarding Local tab is instant;
    - an invalid persisted meeting pair is not rewritten on mount;
    - a source guard bans the old direct writers.
- **SET-Q19 and the probe.**
  - New `src/helpers/selfHostedProbe.js` sends no headers and `redirect: "error"`, and makes one `GET <origin+path>/models`. It rejects embedded credentials, and allows plain http only for hosts that pass `isPrivateHost` (now exported from `providerConnectionTest.js:335`).
  - It is exposed through IPC `probe-self-hosted`, preload `probeSelfHosted`, the types and a browser-preview stub.
  - Inputs are labelled through `EndpointDraft` (`useId` + `htmlFor`). Test is disabled while sealed.

## 4. Open issues for the owner

- **Corti region changes the recipient without the planner.** `cortiEnvironment` (US/EU) and `cortiTenant` are still plain setters in `TranscriptionModelPicker`'s credential fields (`:1249-1272`). The region decides the receiving host (`api.us.corti.app` vs `ai.eu.corti.app`). `RouteSettingsSnapshot`/`SttRouteInput` and the static `providerHosts` don't model it, so the bar can show the wrong host for EU users, and switching region is an unstaged recipient change. Suggest that T1/T3 add the region to the speech input and the host map, and that region switches go through the planner.
- **The provider-search toggle grows the payload without staging.** `ProviderSearchPreference` (`InferenceConfigEditor.tsx:203-214`, localStorage `personalWebSearch:<scope>`) adds the `webSearch` payload part (PAYLOADS.md) the moment it is switched on. Rule 3 covers provider/model/endpoint changes only, so this is out of scope here, but it is a disclosure gap worth a follow-up in T6/T8.
- **Removing `validateAndSelectModel` changes behaviour.** Deleting the selected Whisper model, or loading a list without it, no longer silently picks another model. The selection stays and the route shows "needs model". This follows the brief ("invalid persisted selections are preserved and shown as non-ready").
- **Unsupported-macOS fallback.** The Parakeet/Oruk fallback still commits, but through `onCommit({ mode: "local", provider: "whisper" })` (instant, with Undo, at most once per mount). `orukeetOrganization.test.js` still pins it.
- **Not changed here.**
  - `useTinfoilModels` still refreshes the public, unauthenticated Tinfoil catalog when the Tinfoil tab is browsed. No credential is sent, so it is outside C1.
  - `CodexConnection`'s own status call on mount is outside C1 as scoped.
  - Provider API-key inputs in `TranscriptionModelPicker` and `ReasoningModelSelector` still use the per-provider setters, which Task 2 makes acknowledged.
  - `ReasoningModelSelector` no longer calls `llamaServerStop` when the Cloud tab is chosen, because the change may only be staged. Task 7's `commit` frees llama-server only when a scope moves to a server, so a committed move to Cloud no longer stops it (memory only, not correctness).
