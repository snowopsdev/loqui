### Task 16: Settings search with live controls (SET-R2 A part 2)

Closes M3 for the search surfaces (the flash duration is a documented token, cleanup waits for `animationend`, spacing is logical) and M5 (each test is labelled; the shortcut, Esc, keyboard and landing logic are tested as mounted hooks or pure functions, not only as static markup). It also closes a gap left open by "search with live controls": a toggle in the results must not become a back door around the route planner (rule 3 in `INTERFACES.md`).

Settings gets a search field at the top of the sidebar. Cmd+F or Ctrl+F focuses it, and so does `/` when the user is not typing in another field.
- Results replace the content pane, grouped by section, each with a breadcrumb ("Language Models › Voice Assistant").
- Results carry a **live control** only where flipping it in place cannot change who receives the user's data: appearance, sounds, notifications, startup, clipboard and retention toggles, and the theme select. **Anything that is a route input navigates instead**: the cleanup, assistant, translation, screen-context and speaker-label switches and every provider, model or endpoint are `link` entries, and the 11 task entries are `route` entries that show where the task runs right now (read-only chips) and jump to the Patchbay row. Turning a route on or off in place would skip the planner's staging and the Apply bar.
- Up/Down move the active result, Enter jumps to the setting and flashes it once, and Esc clears the query (and only the next Esc closes Settings).
- No results reads: "No setting matches "xyz". Try "mic", "retention" or "cloud"."

The settings page stays mounted (hidden) while search results show, so downloads and IPC listeners survive.

**What changed from the first draft of this task.**
- Labels and descriptions are the **existing translated strings the rows already show** (for example `settingsPage.general.microphone.title`), not a second copy under `settingsSearch.items.*`. Search then shows the same words as the page, in all 11 locales, and a test fails if the file carrying an anchor does not render the entry's label key. Only two descriptions are new.
- The "Notifications" result bound to `notificationsEnabled`, while the page's row is "Disable all notifications" (`checked={!notificationsEnabled}`): the live switch would have shown the opposite state. The registry now mirrors the page, including `disabled` while notifications are off.
- Esc: v1 set `data-escape-active` but nothing read it. Task 10 now ships the reader (`src/components/ui/escapeClaim.ts`, wired into `SidebarModal`'s `onEscapeKeyDown`: while focus is inside an element marked `data-escape-active="true"` the dialog stays open). This task marks the search field and the results pane with that attribute while a query exists, and their Escape handler clears it. It adds no second mechanism.
- The flash animates a registered custom property (DESIGN.md "animate only … registered properties"), is timed by `--motion-flash` and ends on `animationend`; there is no JS timer and no literal `1400`.
- The landing waits for the anchor to mount (up to 24 frames) instead of one `requestAnimationFrame`, because a jump across sections or sub-tabs mounts the target after the state update.
- A jump to the sub-tab that is already the pending request (the user switched tabs by hand since) still switches tabs: `SettingsModal` clears the request for one commit and re-issues it (Step 3.8), which Task 4's `handleNavigateToPath` alone does not.

   ```ts
   // The landing cue for a searched setting (SET-R2 A). The CSS animation is timed by --motion-flash;
   // this module only sets data-flash and removes it when that animation ends.
   export const FLASH_ANIMATION = "settings-flash";

   export function flashSetting(el: HTMLElement): () => void {
     const clear = () => {
       delete el.dataset.flash;
       el.removeEventListener("animationend", onEnd);
     };
     const onEnd = (e: AnimationEvent) => {
       // A descendant's animation also bubbles an animationend; only our own ends the flash.
       if (e.target === el && e.animationName === FLASH_ANIMATION) clear();
     };
     if (el.dataset.flash) {
       // Jumping to a row that is still flashing: force a reflow so the animation restarts.
       delete el.dataset.flash;
       void el.offsetWidth;
     }
     el.dataset.flash = "true";
     el.addEventListener("animationend", onEnd);
     // If the stylesheet did not start an animation, no animationend will ever arrive.
     if (typeof el.getAnimations === "function" && el.getAnimations().length === 0) clear();
     return clear;
   }

   type AnchorRoot = Pick<ParentNode, "querySelector">;

   export function findSettingAnchor(root: AnchorRoot, anchorId: string): HTMLElement | null {
     const escaped =
       typeof CSS !== "undefined" && typeof CSS.escape === "function"
         ? CSS.escape(anchorId)
         : anchorId.replace(/["\\]/g, "\\$&");
     return root.querySelector<HTMLElement>(`[data-setting-id="${escaped}"]`);
   }

   export interface LandOptions {
     raf: (cb: () => void) => number;
     caf: (handle: number) => void;
     root?: AnchorRoot;
     /** Frames to wait for the anchor to mount after a section or sub-tab change. */
     maxFrames?: number;
     onDone?: (landed: boolean) => void;
   }

   /** Scroll to the anchor and flash it once, waiting for it to mount. Returns a cancel function. */
   export function landOnSetting(anchorId: string, options: LandOptions): () => void {
     const { raf, caf, maxFrames = 24, onDone } = options;
     const root = options.root ?? document;
     let frame = 0;
     let handle = 0;
     let cancelled = false;
     const tick = () => {
       if (cancelled) return;
       const el = findSettingAnchor(root, anchorId);
       if (el) {
         el.scrollIntoView({ block: "center" });
         flashSetting(el);
         onDone?.(true);
         return;
       }
       frame += 1;
       if (frame >= maxFrames) {
         onDone?.(false);
         return;
       }
       handle = raf(tick);
     };
     handle = raf(tick);
     return () => {
       cancelled = true;
       caf(handle);
     };
   }
   ```

   ```ts
     const { section, subTab } = parseSettingsPath(entry.path);
     if (!subTab) return null;
     if (section === "speechToText") return `settingsPage.speechToText.tabs.${subTab}`;
     if (section === "llms") return `settingsPage.llms.tabs.${subTab}`;
     return null;

   export function searchSettings(query: string, translate: (key: string) => string): SearchGroup[] {
     const tokens = normalizeForSearch(query).split(/\s+/).filter(Boolean);
     if (tokens.length === 0) return [];
     const scored = SETTINGS_REGISTRY.map((entry, index) => {
       const section = parseSettingsPath(entry.path).section;
       const label = normalizeForSearch(translate(entry.labelKey));
       const haystack = normalizeForSearch(
         [translate(entry.labelKey), translate(entry.descriptionKey), translate(`settingsModal.sections.${section}.label`), entry.keywords].join(" ")
       );
       if (!tokens.every((tok) => haystack.includes(tok))) return null;
       // Label hits rank above description/keyword hits; registry order breaks ties.
       const score = tokens.filter((tok) => label.includes(tok)).length;
       return { entry, section, index, score };
     }).filter((x): x is NonNullable<typeof x> => x !== null);
     scored.sort((a, b) => b.score - a.score || a.index - b.index);
     const groups: SearchGroup[] = [];
     for (const s of scored) {
       const group = groups.find((g) => g.section === s.section);
       if (group) group.entries.push(s.entry);
       else groups.push({ section: s.section, entries: [s.entry] });
     }
     return groups;
   }
   ```

   ```ts
   import { useCallback, useEffect, useMemo, useRef, useState, type KeyboardEvent as ReactKeyboardEvent, type RefObject } from "react";
   import { useTranslation } from "react-i18next";
   import { landOnSetting } from "./settingFlash";
   import { isSearchShortcut, isTypingTarget, stepActiveIndex } from "./settingsSearchKeys";
   import { anchorIdFor, searchSettings, type SearchGroup, type SettingEntry } from "./settingsRegistry";

   export interface SettingsSearch {
     query: string;
     setQuery(next: string): void;
     clear(): void;
     groups: SearchGroup[];
     activeId: string | null;
     searchRef: RefObject<HTMLInputElement | null>;
     onSearchKeyDown(e: ReactKeyboardEvent<HTMLInputElement>): void;
     jump(entry: SettingEntry): void;
     /** Escape handler for the field and the results pane: clears a non-empty query and reports it consumed the key. */
     consumeEscape(): boolean;
   }

   export function useSettingsSearch({
     open,
     navigateToPath,
     land = landOnSetting,
   }: {
     open: boolean;
     navigateToPath: (path: string) => void;
     land?: typeof landOnSetting;
   }): SettingsSearch {
     const { t } = useTranslation();
     const [query, setQueryState] = useState("");
     const [activeIndex, setActiveIndex] = useState(0);
     const [pendingAnchor, setPendingAnchor] = useState<string | null>(null);
     const searchRef = useRef<HTMLInputElement>(null);

     const groups = useMemo(() => searchSettings(query, (key) => t(key)), [query, t]);
     const flat = useMemo(() => groups.flatMap((g) => g.entries), [groups]);
     const activeEntry = flat[Math.min(activeIndex, flat.length - 1)];
     const activeId = activeEntry?.id ?? null;

     const setQuery = useCallback((next: string) => {
       setQueryState(next);
       setActiveIndex(0);
     }, []);
     const clear = useCallback(() => setQuery(""), [setQuery]);

     const jump = useCallback(
       (entry: SettingEntry) => {
         setQuery("");
         navigateToPath(entry.path);
         setPendingAnchor(anchorIdFor(entry));
       },
       [navigateToPath, setQuery]
     );

     // After a jump the target mounts a frame or two later (section and sub-tab switches).
     useEffect(() => {
       if (!pendingAnchor) return;
       return land(pendingAnchor, {
         root: document,
         raf: (cb) => requestAnimationFrame(cb),
         caf: (handle) => cancelAnimationFrame(handle),
         onDone: () => setPendingAnchor(null),
       });
     }, [pendingAnchor, land]);

     useEffect(() => {
       if (!open) return;
       const onKey = (e: KeyboardEvent) => {
         const capturing = !!document.querySelector("[data-capturing]");
         if (!isSearchShortcut(e, { typing: isTypingTarget(e.target), capturing })) return;
         e.preventDefault();
         searchRef.current?.focus();
         searchRef.current?.select();
       };
       document.addEventListener("keydown", onKey);
       return () => document.removeEventListener("keydown", onKey);
     }, [open]);

     const onSearchKeyDown = useCallback(
       (e: ReactKeyboardEvent<HTMLInputElement>) => {
         if (e.key === "ArrowDown" || e.key === "ArrowUp") {
           e.preventDefault();
           setActiveIndex((i) => stepActiveIndex(i, flat.length, e.key));
         } else if (e.key === "Enter" && activeEntry) {
           e.preventDefault();
           jump(activeEntry);
         }
       },
       [flat.length, activeEntry, jump]
     );

     const consumeEscape = useCallback(() => {
       if (!query) return false;
       clear();
       return true;
     }, [query, clear]);

     return { query, setQuery, clear, groups, activeId, searchRef, onSearchKeyDown, jump, consumeEscape };
   }
   ```

    ```css

         duration and JS removes data-flash on animationend, so this is the only place it lives. */

    ```

    Append the flash rule. It animates a registered custom property, which DESIGN.md's Motion rule allows ("only transform, opacity, clip-path, filter and registered properties"); the fill and outline are mixed from that property, so no paint property is animated directly:

    ```css
    /* Settings search landing (SET-R2 A): the row you jumped to flashes once. */
    @property --settings-flash {
      syntax: "<number>";
      inherits: false;
      initial-value: 0;
    }
    [data-setting-id][data-flash="true"] {
      outline: 2px solid
        color-mix(in srgb, var(--color-ring) calc(var(--settings-flash) * 100%), transparent);
      outline-offset: 2px;
      border-radius: 8px;
      background-color: color-mix(
        in srgb,
        var(--color-ring) calc(var(--settings-flash) * 16%),
        transparent
      );
      animation: settings-flash var(--motion-flash) var(--motion-ease-std) both;
    }
    @keyframes settings-flash {
      0%,
      40% {
        --settings-flash: 1;
      }
      100% {
        --settings-flash: 0;
      }
    }
    @media (prefers-reduced-motion: reduce) {
      /* Reduced motion: no background flash, just the outline cue. The global policy sets
         animation-duration to 0.01ms !important on every element; this rule outranks it
         (higher specificity, also !important) so the outline fades over --motion-flash and
         animationend still fires. */
      [data-setting-id][data-flash="true"] {
        background-color: transparent;
        animation-duration: var(--motion-flash) !important;
      }
    }
    ```
