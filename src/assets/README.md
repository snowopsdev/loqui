# Loqui artwork

Loqui uses the PNG artwork supplied by the maintainer in `Loqui-Asset-Pack.zip` on 2026-09-24. The unchanged originals are committed under `brand/source/`. The pack contains no editable vector masters or separate creator/license metadata; do not describe the PNGs as original vector geometry or infer an external creator.

| Source file                     | Purpose                                      |
| ------------------------------- | -------------------------------------------- |
| `loqui-app-icon.png`            | Application and installer icon               |
| `loqui-symbol.png`              | Standalone symbol and monochrome derivatives |
| `loqui-horizontal-wordmark.png` | Horizontal logo                              |
| `loqui-stacked-lockup.png`      | Stacked logo                                 |
| `loqui-brand-style-guide.png`   | Supplied visual reference                    |
| `loqui-asset-overview.png`      | Supplied asset overview                      |

`brand/source/manifest.json` records the received archive's SHA-256 and each original file's archive path and SHA-256. Keep the originals unchanged; changes to display size, padding, format, or monochrome treatment belong in `scripts/generate-brand.cjs`. Source references remain in the repository and are excluded from packaged application resources.

Run `npm run assets:generate` to regenerate the committed distributable assets. Run `npm run assets:check` to verify source hashes and generated bytes. The outputs include:

- `brand/mark.png` and `brand/mark-mono.png` for the standalone symbol.
- `brand/logo-light.png` and `brand/logo-dark.png`, both retaining the supplied color horizontal logo; these names do not imply recolored artwork.
- `brand/logo-stacked.png` and `brand/social.png` for the stacked lockup and README/social artwork.
- `brand/icon-*.png`, `icon.png`, and `icon.icns` for application and installer icons.
- `iconTemplate.png`, `iconTemplate@2x.png`, and `iconTemplate@3x.png` for the macOS menu bar. These use a black silhouette with the symbol's alpha mask, allowing macOS to supply the appropriate light/dark appearance.

Inspect the mark at small sizes and on both themes after regeneration. Preserve its aspect ratio; avoid CSS inversion on color logos. The supplied style guide is an artwork reference, not a replacement for the functional interface color tokens documented in [DESIGN.md](../../DESIGN.md). The previous placeholder SVGs are retired. Release builds use the committed exports and must not fall back to upstream artwork or an image service.

The maintainer-supplied Loqui artwork is distributed under this project's [MIT license](../../LICENSE). This records the project's distribution terms, not an independently verified creator attribution. Interface fonts are separate: Inter and Caveat are supplied by Fontsource under SIL OFL, and Noto Sans retains its SIL OFL terms.
